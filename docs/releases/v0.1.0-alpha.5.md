**Unofficial** OpenSSH-style clients (`pi-sh`, `pi-cp`, `pi-sftp`) for Raspberry Pi Connect. Not affiliated with or endorsed by Raspberry Pi or OpenSSH. This is an alpha prerelease: compatibility and runtime verification are incomplete.

A fix release for saved sessions, on top of v0.1.0-alpha.4.

## Fixed

### Saved sessions that stop opening the shell
After a few days a saved session still signed in (`--sessions` showed it `active`), but opening the shell failed with `Connect shell authorization or device identity was not confirmed; sign in again`. Connect wants a recent sign-in before it opens the remote shell, and answers with its "Reauthenticating with Raspberry Pi ID" page instead. pi-sh now continues through that page, as the browser's Continue button does:

- while your Raspberry Pi ID sign-in is still valid, the Connect sign-in is renewed with no prompt, the renewed session is saved, and the shell opens;
- if Raspberry Pi ID asks for your password, the usual password and one-time code prompts follow;
- any other page stops pi-sh with nothing submitted to it.

pi-sh, pi-cp and pi-sftp all do this. Nothing is sent to the Pi before the shell is open.

## Diagnostics
With `-vvv`, a page pi-sh refuses is described by its structure: title, headings, form addresses, field names and types, and button text. Token, account and query values are never printed.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/paologiua/pi-sh/main/install.sh | bash
# or, without curl (iSH):
wget -qO- https://raw.githubusercontent.com/paologiua/pi-sh/main/install.sh | bash -s -- --downloader wget
```

macOS (amd64/arm64), Linux (386/amd64/arm64) and iSH use the installer, which verifies `SHA256SUMS`. On Windows (amd64/arm64), extract the `.exe` files from the archive. Check the build with `pi-sh -V`; it should print `pi-sh_v0.1.0-alpha.5+g` followed by the commit.

## Known limitations
- The renewal without a prompt has been verified on macOS. The password branch, used once the Raspberry Pi ID sign-in has also expired, has been tested only against a simulated service. How long a Raspberry Pi ID sign-in lasts has not been observed.
- `--sessions` reports `active` while Connect accepts the session; opening the shell may still need the renewal above.
- iSH: login, saved sessions and the interactive shell prompt have been reached on a physical device. One intermittent Go runtime crash during connection setup was seen once on iSH with alpha.4. Sustained interactive use, terminal controls, resizing and transfers have not been verified on iSH.
- Native Linux and Windows runtime is unverified.
- No release signatures; only SHA-256 checksums.

See `docs/SSH_COMPATIBILITY.md` for the full compatibility matrix.
