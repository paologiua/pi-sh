**Unofficial** OpenSSH-style clients (`pi-sh`, `pi-cp`, `pi-sftp`) for Raspberry Pi Connect. Not affiliated with or endorsed by Raspberry Pi or OpenSSH. This is an alpha prerelease: compatibility and runtime verification are incomplete.

## Highlights

### Saved login sessions
Sign in once and reuse the Connect session across runs, protected by a single passphrase (like an SSH key passphrase).
- All accounts are kept in one encrypted file (Argon2id + XChaCha20-Poly1305). Nothing is stored in plaintext.
- `UseKeychain yes` keeps the passphrase in the macOS Keychain or the Linux Secret Service (opt-in).
- New options: `--sessions` (list and check saved sessions), `--logout email`, `--passphrase` (set up or change), `--forget-keychain-passphrase`, `--reset-sessions` (sign out and delete everything).
- There is no agent: without `UseKeychain`, the passphrase is asked once per process.

### Sign-in and device choice
- Direct HTTPS login (password + TOTP) is now the default. `--browser` opts into the browser companion.
- If you name only the account, `pi-sh`, `pi-cp` and `pi-sftp` let you choose the device after sign-in.

### iSH installer
On iSH, the installer now:
- installs into `/usr/local/bin`, which is already on PATH;
- installs launchers that set `GOMAXPROCS=1` and `PI_SH_ISH_RELAY=1` by default, so plain `pi-sh`, `pi-cp` and `pi-sftp` work (exported values still take precedence);
- removes earlier pi-sh copies from `~/.local/bin` and `~/bin` (`--keep-old` keeps them);
- works with only wget: if curl is missing, downloads use wget (`--downloader wget` forces it).

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/paologiua/pi-sh/main/install.sh | bash
# or, without curl:
wget -qO- https://raw.githubusercontent.com/paologiua/pi-sh/main/install.sh | bash
```

macOS (amd64/arm64), Linux (386/amd64/arm64) and iSH use the installer, which verifies `SHA256SUMS`. On Windows (amd64/arm64), extract the `.exe` files from the archive. Check the build with `pi-sh -V`; it should print `pi-sh_v0.1.0-alpha.2+g1ebf24bacdfe`.

## Known limitations
- Saving, resuming, expiry, logout and keyring storage of sessions are covered by local tests but have not yet been run against the real Connect service.
- iSH: one non-TTY command has been verified on a physical device. The interactive shell, transfers, and the new installer launchers and cleanup have not been verified on iSH yet.
- Native Linux and Windows runtime is unverified.
- No release signatures; only SHA-256 checksums.

See `docs/SSH_COMPATIBILITY.md` for the full compatibility matrix.
